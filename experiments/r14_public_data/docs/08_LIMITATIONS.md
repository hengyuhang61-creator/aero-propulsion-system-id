# R14 局限性与不可支持的结论

本文件列出本轮所有已知限制。任何引用 R14 结果的场合都必须同时引用对应条目。

---

## 1. 数据层面

| 编号 | 限制 | 影响 |
|---|---|---|
| D1 | SBLI2.05 UQ 只提供 2500 对图像的**平均**速度场 | 无时间序列，不能做任何动态/瞬态/频谱分析 |
| D2 | 同一数据包内 X 网格按位置组平移，最大 2.04 mm，与物理信号同量级 | 跨组绝对空间配准不确定度约 1–2 mm；POD 采用索引对齐属**方法选择** |
| D3 | 无壁面压力数据 | 无法用 Cp 做独立验证，无法与 R13 谐波结果对接 |
| D4 | 无湍流统计（雷诺应力） | 无法评估模型对湍流输运的预测 |
| D5 | ASCII `dataSummary` 表头列序错误 | 按字面解析会互换 h 与 x；已按语义修正并记录 |
| D6 | 论文正文写 x_bump = −72.2 mm，数据包为 −75.2 mm | 以数据包为准 |
| D7 | 论文给出的 bump 高度不确定度 ±8% | 输入量本身有约 0.01–0.07 mm 误差，接近 Δy_scp 的 RMSE 量级 |
| D8 | 测量噪声底约 10 m/s（小扰动案例的场间 RMS 差） | 低于 10 m/s 的流场差异不可信 |

## 2. 方法层面

| 编号 | 限制 | 影响 |
|---|---|---|
| M1 | 多项式基线是**重新构造**的，原文未发表 Δx_scp 响应面 | 不能声称"复现原论文方法并改进" |
| M2 | GP 超参数用边际似然在训练折内优化，未做嵌套 CV | 报告的泛化误差可能略偏乐观 |
| M3 | GP 后验方差**未做校准检验**（无覆盖率统计） | 不能把 GP 方差当置信区间使用 |
| M4 | POD 秩用固定扫描（4–20），未在训练内部做嵌套选择 | 但结果显示秩不敏感（U RMSE 变化 <1%），影响有限 |
| M5 | POD 系数回归对每个模态独立建模，未考虑模态间相关 | 可能低估耦合模态的重构能力 |
| M6 | 边界外推折只有 10 个案例 | 外推误差估计本身不确定度大 |

## 3. 跨实验

| 编号 | 限制 | 影响 |
|---|---|---|
| X1 | SBLI2.05 与 HMVE 几何、Mach、雷诺数、归一化全部不同 | 不能合并训练，不能把数值差解释为模型误差 |
| X2 | HMVE 无壁压、无负速度、近壁 0–0.7 mm 缺失 | 分离泡几何不可定量 |
| X3 | HMVE 归一化用自由来流 U1 而非当地外缘速度 | 与 SBLI2.05 的绝对速度不可直接比较 |
| X4 | HMVE 的 Re-code 差异不是重复实验 | 不能当独立重复样本估计方差 |

## 4. 未执行项

| 编号 | 项目 | 原因 |
|---|---|---|
| N1 | Busemann 视频轨迹 | CDN 限速，实测 0.04–0.6 KB/s，视频未取得 |
| N2 | CFD 对照 | 三维构型 + bump 跨展向曲面需自建假设 + 计算规模 |
| N3 | HyMAX / Speed Bump / G550 动态数据 | P2，本轮未进入；未做任何可用性判定 |
| N4 | `data.Mach46.txt` 与 R11 Sajben 场的定量对照 | 该文件为 M≈0.46 跨声速，与 R14 超声速问题不同族，本轮仅登记不建模 |

## 5. 明确不可支持的结论

以下说法在本轮证据下**全部不成立**，不得写入任何对外材料：

1. ❌ "R14 建立了超声速进气道非启动的动态模型" —— 无动态数据。
2. ❌ "从 Busemann 视频提取了激波速度" —— 视频未取得。
3. ❌ "POD 显著优于原有方法" —— 仅优于均值场与最近邻的 U 分量，V 分量不如最近邻。
4. ❌ "模型可在任意扰动位置外推" —— 外推误差是域内的 2–2.5 倍。
5. ❌ "CFD 验证通过" —— 未运行求解器。
6. ❌ "HMVE 验证了 SBLI2.05 模型" —— 只建立了比较契约，未做模型验证。
7. ❌ "`data.Mach46.txt` 是 Mach 4.6 数据" —— 实为 M≈0.46 跨声速扩压器。
8. ❌ "两个实验的分离强度相当" —— U_min/U_e 数值接近但成因不同。
9. ❌ "已取得 NASA 全部 SBLI 实验库" —— 仅取得 SBLI2.05 UQ 与 HMVE PIV profiles。
10. ❌ "R14 完成了跨工况泛化的科学验证" —— 只完成了单数据集内的留组泛化评估。
