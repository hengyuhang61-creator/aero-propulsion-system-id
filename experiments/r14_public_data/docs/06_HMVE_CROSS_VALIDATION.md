# R14 HMVE 独立交叉验证报告

**数据：** NASA HMVE 2025（NASA/TM-20250008885），`HMVE2_PIVprofiles.zip`
**内容：** 23 个 Tecplot 剖面文件，483 条壁法向剖面，21 站/文件
**条件：** M = 2.5 / 3.0 / 3.5；锥形激波发生器 α = 10° / 13.5° / 16°；轴对称（axi）与后掠（swept, θ=90°）两种几何

---

## 1. 先建立比较契约（未建立前不做任何数值合并）

| 维度 | SBLI2.05 UQ | HMVE 2025 | 是否可比 |
|---|---|---|---|
| 几何 | 矩形低展弦比管道 45 × 47.5 mm（AR≈0.95），顶壁 20° 全展长斜坡，h_ramp = 1.1 mm | 轴对称锥-柱体中心体，锥形激波发生器 10°/13.5°/16°，另有 90° 后掠构型 | **否**（构型类别不同） |
| 来流 Mach | 2.05 | 2.5 / 3.0 / 3.5 | **否** |
| 雷诺数 | 论文给出 δ0 = 5.4 mm；Re 未在本轮核实到单一数值 | 以 Re_D ×10⁻⁶ 编码（1 / 2 / 4 等） | **否**（定义不同） |
| 流向坐标 | `X = x_abs − x_scp,unperturbed` | `x − x_i`，x_i 为无粘激波入射位置 | 定义不同，各自内部使用 |
| 壁法向坐标 | Y，原点在下壁面 | y，原点由逐数据集目视确定的壁面 | 概念相同，绝对零点各有不确定度 |
| 速度输出 | 平均 U、V（**m/s**） | U/U1、V/U1、W/U1（**归一化**） | 需转无量纲 |
| 湍流统计 | **无** | uu/U1²、vv/U1²、ww/U1²、uv/U1² | SBLI2.05 无对应量 |
| 时间信息 | 无（2500 对图像的平均） | 无（系综平均剖面） | 均不支持动态 |
| 壁压 | 无 | 报告有图，**ZIP 中无数据** | 均不可用 |

**结论：不得把 HMVE 拼接进 SBLI2.05 的 45 个样本，也不得把两者数值差异直接解释为模型误差。** 下面只做无量纲量的并列陈述。

## 2. 可比较的无量纲量

### 2.1 速度亏损比 `U_min / U_edge`

| 数据集 | 条件 | U_min/U_e |
|---|---|---:|
| SBLI2.05（基准未扰动） | M2.05, h_ramp=1.1mm | 0.072 |
| SBLI2.05 | case 1（h=0.11, x=−75.2） | 0.155 |
| SBLI2.05 | case 25（h=0.89, x=−57.2，最大位移） | 0.088 |
| SBLI2.05 | case 40（h=0.89, x=−48.2，最大法向位移） | 0.045 |
| SBLI2.05 | case 45（h=0.89, x=−42.2，弱响应） | 0.060 |
| HMVE axi | M2.5, α=10°, Re1 | 0.461 |
| HMVE axi | M2.5, α=13.5°, Re1 | 0.172 |
| HMVE axi | M2.5, α=16°, Re1 | 0.076 |
| HMVE axi | M3.0, α=16°, Re1 | 0.058 |

**必须同时说明的限制：** SBLI2.05 的 `U_min` 出现在近壁测量窗口内，其成因可能是边界层内低速区而非分离泡；HMVE 的 `U_min` 则是激波诱导亏损的最小值。两者数值接近**不构成**"分离强度相当"的证据。此表只说明：两套实验的速度亏损量级处于同一区间（0.05–0.16），可用于后续建立更严格的可比量，不能用于模型验证结论。

### 2.2 HMVE 内部跨马赫趋势（该数据自身支持的结论）

固定 α = 16°、Re-code = 1：

| Mach | U_min/U1 | max(uu/U1²) | δ*_max（含近壁补正）[mm] |
|---|---:|---:|---:|
| 2.5 | 0.076 | 0.0356 | 5.94 |
| 3.0 | 0.058 | 0.0364 | 6.02 |

固定 M = 2.5、Re-code = 1，改变 α：

| α | U_min/U1 | max(uu/U1²) |
|---|---:|---:|
| 10° | 0.461 | 0.0104 |
| 13.5° | 0.172 | 0.0276 |
| 16° | 0.076 | 0.0356 |

**可支持的结论：** 随激波角增大，速度亏损加深、湍流峰值升高，与 TM 报告正文一致；Mach 从 2.5 升到 3.0 时亏损继续加深。**这是 HMVE 数据自身趋势的独立复算，不是对 SBLI2.05 模型的验证。**

### 2.3 后掠效应（HMVE 独有）

M2.5、α=16°、Re1：轴对称 `U_min/U1 = 0.076`，90° 后掠 `0.136`；`max(uu/U1²)` 分别为 0.0356 与 0.0268。后掠使干扰减弱，方向与"后掠降低有效激波强度"的预期一致。

## 3. 交叉验证的判定

| 问题 | 判定 |
|---|---|
| 能否用 HMVE 检验 R14 的 Δx_scp 参数模型？ | **不能。** HMVE 无几何扰动参数、无 scp 定义、无同一坐标系。 |
| 能否用 HMVE 检验 R14 的 POD 流场模型？ | **不能。** 几何与输入维度不同，且 HMVE 只有剖面不是二维场。 |
| 能否用 HMVE 检验物理判断（"扰动使激波上游移/亏损加深"）？ | **部分能。** 亏损随激波强度单调加深这一点在两套数据中都成立；但 SBLI2.05 的"位置非单调敏感度"在 HMVE 中无对应自由度，无法检验。 |
| 是否证明当前资料不足以支持跨实验泛化？ | **是。** 缺几何/雷诺数/归一化的统一，缺壁压，缺湍流统计的对应量。 |

**HMVE 交叉验证状态：`PARTIAL`。** 完成了数据取得、字段核实、独立复算与比较契约；**未**获得可支持跨实验模型泛化的证据。

## 4. 本轮未能完成的部分（明确记录）

- 壁面压力：TM 报告有 Fig. 11 平均壁压曲线，但 ZIP 内**无壁压数据文件**。未做数字化（图形数字化会引入不可控误差，且会把图当数据）。
- 分离泡几何：全部 483 条剖面 `U/U1 ≥ 0.0008`，无负速度；近壁 0–0.7 mm 未测。**分离区长度/高度无法从本归档定量给出。**
- 雷诺数独立重复：同一 Mach/α 下的不同 Re-code 是不同工况，不是重复实验，未计入独立重复次数。
