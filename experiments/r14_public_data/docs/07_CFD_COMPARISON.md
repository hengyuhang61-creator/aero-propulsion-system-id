## 3. 为什么本轮不启动求解器

1. **几何性质决定不能做二维。** 试验段 45 × 47.5 mm，展弦比 ≈0.95，论文本身把"低展弦比管道 + 侧壁"作为核心物理（第 2、3 章）。用二维模型替代会直接违背任务书"不能把简单二维模型称为真实实验复现"。
2. **三维算例的成本与验证要求不匹配本轮时间。** 任务书要求"至少对代表性工况进行网格敏感性检查"且"残差下降不能替代质量守恒和网格验证"。四个三维算例 × 至少两套网格 × 收敛与守恒审计，是一个独立的计算campaign，无法在数据建模同轮内可靠完成。
3. **bump 三维曲面仍需自建假设。** 在缺少跨展向拼接公式的情况下，任何三维结果都会把"我们的几何假设"混入"验证结论"，这正是任务书禁止的。
4. **没有 CFD 结果就不能有验证结论。** 因此本轮不给任何"CFD 与实验一致/不一致"的陈述。

## 4. 冻结的计算规范（下一轮直接执行，不需重新设计）

```
几何
  域        : 三维，入口 45.0 × 47.5 mm，325 mm 发展段，20° 斜坡 h=1.1 mm，
              下游 (45-1.1) × 47.5 mm，出口接背压
  侧壁      : 无滑移绝热固体壁（z = 0, z = 47.5 mm）
  bump      : 展向 5 个轴对称 bump，单 bump 轮廓用 Table A.1 五阶多项式
              （h=0.11/0.28/0.48/0.66/0.89 mm 各一套系数）
              跨展向拼接：先用 Gaussian 峰 + 五阶谷的线性混合，
              该选择必须标为"本工作假设"，并在报告中与实验几何区分
来流
  入口      : 由 inletProfiles.mat 在 X=-35 mm 的 5 个展向剖面插值给定
              U、V、u′、v′、⟨u′v′⟩（合成湍流入口需固定随机种子）
  出口      : 压力出口，按 UQ 工况背压设定（需从论文 §3.1 表格核实具体值）
  壁面      : 绝热无滑移
求解
  求解器    : 现有 Fluent 环境（不得修改 R13 或其他生产项目）
  模型      : 先 SA，再 SST k-ω；两者结果差异必须报告，不得只报较好的一个
  网格      : 三套（粗/中/细），近壁 y+ < 1，中/细网格 GCI 估计
  收敛      : 残差 + 质量流量不平衡 < 0.1% + 监测点稳定
算例
  baseline / case 25 / case 23 / case 4
比较
  坐标      : 与 PIV 相同的 X = x_abs - 44.1 mm、Y 自下壁面、Z = 21 mm
  量        : U、V 在 PIV 有效掩码内的 MAE/RMSE；激波穿越点 (x_scp, y_scp)
  积分量    : 论文建议的 Λ 参数
  禁止      : 把 CFD 节点值与 PIV 点直接等价；必须做 PIV 空间分辨率降采样
```
