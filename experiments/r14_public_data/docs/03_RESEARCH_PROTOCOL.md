## 2. 验证设计（事前固定）

### 2.1 禁止的划分方式

- ❌ 45 个工况随机 80/20 切分（会泄漏同一位置的 5 个高度）
- ❌ 按单个案例留一（同一位置的其它高度仍在训练集，高估泛化）
- ❌ 用测试集做标准化、超参数选择或模态数选择

### 2.2 采用的划分

| 方案 | 折数 | 每折测试数 | 检验什么 |
|---|---|---|---|
| `LOGO_x_bump` | 9 | 5（同一位置的全部高度整体留出） | 未见**位置** |
| `LOGO_h_bump` | 5 | 9（同一高度的全部位置整体留出） | 未见**高度** |

边界位置（x = −75.2、−42.2）单独标记为外推，不与域内成绩混合。

### 2.3 基线层级（必须全部报告）

1. 训练均值场（"不建模"基线）
2. 最近邻案例（"查表"基线）
3. 二次 / 三次响应面
4. 二维插值
5. GP

任何"改进"声明必须同时给出它与**最近邻**和**均值场**的对比。

### 2.4 指标（全部保留单位）

MAE、RMSE、最大绝对误差、偏差；流场按分量分别报告；不做只报 R² 的处理。

## 3. 数据处理规则

| 规则 | 实现 |
|---|---|
| `valid = 0` 必须剔除 | `np.where(mask, U, np.nan)`；测试断言无零填充 |
| 原始数据只读 | 所有脚本只读 `data/raw/`，输出写 `results/`、`figures/` |
| 目标值用全精度 | 取 `dataSummary.mat`，不取两位小数的 ASCII |
| 网格不一致必须显式处理 | 见 `02_DATA_ELIGIBILITY_AUDIT.md` §1.6，两种对齐都算，按相关性判定 |
| 不同几何/马赫不合并 | SBLI2.05 与 HMVE 只做无量纲并列，不做样本拼接 |

## 4. 停止条件（事前声明）

| 条件 | 触发后的动作 | 本轮是否触发 |
|---|---|---|
| 数据无法下载 | 记录真实失败证据，不虚构 | ✅ 视频 |
| 视频无可靠时间基准 | 只交付位置—帧序号 | ✅（且未取得视频） |
| PIV 掩码不支持统一空间分析 | 放弃全局 POD | ❌ 共同有效区 68.3%，可做 |
| 模型不优于简单基线 | 如实报告，不无限调参 | ✅ V 分量 |
| CFD 缺精确几何/边界条件 | 不声称验证通过 | ✅ 三维 bump 曲面 |
| 无独立测量的动态输入 | 不做动态辨识 | ✅ 全部数据集 |
| 发现已完成的计算 | 复用，不重复 | ✅ R13 谐波 |

## 5. 交付状态的分项定义

| 状态项 | 通过条件 |
|---|---|
| `DATA_ACCESS` | 至少一个 P0 数据集完整落盘 + SHA256 + 结构核对 |
| `MODEL_RESULT` | 留组验证完成 + 指标含单位 + 与基线对比 |
| `VIDEO_TRACKING` | 真实视频 + 时间基准判定 + 轨迹文件 |
| `CFD_VALIDATION` | 实际求解 + 网格敏感性 + 同坐标比较 |
| `DYNAMIC_IDENTIFICATION` | 独立激励 + 同步物理时间输出 + 独立轨迹 |
| `SCIENTIFIC_VALIDATION` | 独立数据上的可重复外部检验 |

**不得因某一项通过而把整体报告为成功。**
